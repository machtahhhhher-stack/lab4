## Бот

Бот: [@evgrafov_movies_bot](https://t.me/evgrafov_movies_bot)

- поиск фильма по названию (просто текстом или командой `/search`);
- карточка фильма: год, режиссёр, жанры, страны, длительность, бюджет, сборы,
  оценки IMDb / Metacritic / Rotten Tomatoes, описание и постер из Википедии;
- `/top` — топ продаж фильмов iTunes, `/random` — случайный фильм из топа;
- избранное, история запросов, настройки (язык данных, число результатов, постеры) —
  сохраняются в `users.json` и не теряются после перезапуска;
- ошибки (нет связи, ничего не найдено, неизвестная команда) не роняют бота —
  пользователь получает понятный ответ.

Данные берутся по API: Викиданные и Википедия (бесплатно, без ключей), топ — iTunes RSS.

### Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Создайте рядом с `bot.py` файл `.env` со строкой `BOT_TOKEN=ваш_токен` (образец — `.env.example`).
3. Двойной щелчок по `Запустить_бота.bat` или:

```
pip install -r requirements.txt
python bot.py
```

### Тесты

```
python -m unittest discover -s tests -t .
```
